# Marco / Tracker de entregas

Dashboard para controlar actividades creativas, referencias visuales, fechas de entrega, estados y enlaces finales.

## Uso

1. Instala las dependencias con `npm install`.
2. Abre el tracker con `npm run dev`.
3. Edita cada actividad para agregar la fecha y el enlace final.
4. Usa **Respaldo** para descargar un JSON y guárdalo en Google Drive.
5. Usa **Importar respaldo** para recuperar los datos en otro navegador.

Los cambios se guardan automáticamente en el navegador del dispositivo. El proyecto está listo para subirse a un repositorio de GitHub.
